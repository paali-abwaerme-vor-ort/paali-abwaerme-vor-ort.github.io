Hosting durch GitHub Pages

Die Website wird über GitHub Pages bereitgestellt. GitHub verarbeitet beim Abruf technische Zugriffsdaten, insbesondere die IP-Adresse, um die Website auszuliefern und die Sicherheit des Dienstes zu gewährleisten. Verarbeitung und Speicherdauer durch GitHub richten sich nach der Datenschutzerklärung von GitHub. Wir führen keine eigene Besuchsstatistik.

Geschützte Darstellungen und lokale Speicherung

Die Gemeindeseiten werden verschlüsselt ausgeliefert und nach Eingabe des Projektpassworts im Browser entschlüsselt. Das eingegebene Passwort wird von der Website nicht an einen Anmeldeserver gesendet; die Funktion „angemeldet bleiben“ ist deaktiviert. Es werden keine persönlichen Benutzerkonten geführt. Die Darstellungen verarbeiten die Auswahl von Datum und Ansicht im Browser.

Externe Programmbibliotheken

Nach dem Öffnen einer Darstellung wird die JavaScript-Bibliothek D3 über jsDelivr geladen. Hierbei erhält der CDN-Anbieter technische Verbindungsdaten wie die IP-Adresse. Weitere Informationen stehen in den Datenschutzhinweisen von jsDelivr. Die Fördergrafik wird direkt von dieser Website geladen.
